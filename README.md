# Hangman Game 🎮

A GUI-based Hangman Game developed using Python.  
This project was completed as part of the CodeAlpha Internship Program.

## 📌 Project Overview
The Hangman Game is a classic word-guessing game where the player tries to guess a hidden word within a limited number of attempts.

## ✨ Features
- User-friendly Graphical Interface
- Random word selection
- Limited attempts system
- Real-time word display update
- Game over and win detection

## 🛠 Technologies Used
- Python
- Tkinter (for GUI)

## ▶ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the game:
   python main.py
